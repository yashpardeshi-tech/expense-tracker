# 💰 Expense Tracker

A simple and beginner-friendly Expense Tracker built with Python.

This project allows users to record their daily expenses, view expense history, calculate total spending, and see spending by category.

## 🚀 Features

- ➕ Add new expenses
- 📋 View all expenses
- 💰 Calculate total expenses
- 📊 View expenses by category
- 💾 Automatically save expenses in a CSV file
- 📅 Automatically record the date

## 🛠️ Technologies Used

- Python
- CSV
- File Handling
- Datetime
